You can pass command-line arguments through the Arguments - sys.argv() field.
The terminal supports Python input() without leaving the browser.
Save stores the current workspace in local storage.
The workspace can contain multiple Python and text files.
Open a folder to work inside it, then use [..] to go back.
Uploading a ZIP to root preserves its folder structure.
Download from here (ZIP) exports the current folder and everything inside it.
Download from root (ZIP) exports the entire workspace.
The editor runs Python locally through Pyodide, so your code does not need a Python server.
You can create files directly from the Workspace or the Files menu.
Files that the IDE can render are shown directly in the editor area.
Compiled files that the IDE cannot render can still be stored and downloaded.
Clicking outside the Files menu closes it.
The terminal can be expanded from the bottom of the editor.
Clear removes the current terminal output without changing your files.
New project can delete the workspace, or download it as a ZIP before deleting it.
Changes remain when you switch between files, but Save is required to persist them after closing the page.
The IDE warns you before closing the page when there are unsaved workspace changes.
You can upload files directly into the current folder.
Python modules can be split across multiple files in the same workspace.
